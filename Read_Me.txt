Tip Calculator & Bill Splitter

A clean, live-updating tip calculator and bill splitter. No Calculate button  results update as you type.

How to Run

Option 1  Open directly (no install needed)

 Just open index.html in your browser
open index.html
or double-click index.html in your file explorer


Option 2  Local dev server

Using Python (comes pre-installed on most machines)
python3 -m http.server 3000
Then open: http://localhost:3000

# Using Node.js (if installed)
npx serve
Then open: http://localhost:3000

Tech Stack
- Vanilla HTML / CSS / JavaScript (zero dependencies)
- Google Fonts: DM Serif Display + DM Sans
- No build step required

 Features
- Live calculation as you type
- Tip presets: 10% / 15% / 20% + custom input
- Inline validation (no alerts)
- Bill split across multiple people
- Smart rounding (last person absorbs remainder)
- Full keyboard navigation (Tab + Enter)
- Responsive  works on 360px phone to 1440px desktop
- Reset button
